## 权限边界的两个回答

**DeepSeek 在 MIRROR 中有什么权力？** 它可基于单个角色被允许看到的上下文，提出一句话、立场、信念反应、意图或结构化行动；还可为已选中的最后对话参与者生成结束语。它不能读取 Debug World 或其他角色私密 Context，不能直接写数据库、授予 Knowledge、修改关系和分数、推进日期、决定 Claim 真伪或揭示 UNKNOWN。输出依次经过解析、受限语义检查、领域规则和事务提交，才会变成世界事件。

**Alice 说出预写文本之外的话，何时算新行为？** 首先确认这句话引用的 Claim、来源和记忆确实在她当时的个人 Context 内；若它是传播或行动，还需结构化 Assertion/Action、合法引用、因果事件与后果。符合这些条件而表达方式或选择未被预写，可以视为角色产生的新行为。若她把 AI 来源说成 Evan，则无论句子多自然，都只是模型错误：不能改变真实来源，也不能让它污染 Knowledge；这类输出应被拒绝、重试或降级为安全措辞。

DeepSeek 当前 API 的模型名、JSON 模式与思考开关按[官方 Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/)和[JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)配置。
